## 2. 唯一训练算法改动：扩大 KD 掩码

同一题组有 8 条回答。令 `full_pass[i]` 为完整 verifier 的布尔结果，奖励沿用原实现。

```python
has_reward_variation = rewards.max() > rewards.min()
all_fail = not any(full_pass)

use_kd = all_fail
use_rl = has_reward_variation
```

两种掩码允许同时为真：

| 题组结果 | 旧更新 | 本次更新 |
|---|---|---|
| 全失败，奖励相同 | KD | KD |
| 全失败，奖励有差异 | RL | KD + RL |
| 部分成功，奖励有差异 | RL | RL |
| 全部成功 | 跳过 | 跳过 |

`all_fail` 必须使用完整验证结果。奖励差异继续使用原来的严格比较，不新增浮点容差或奖励阈值。题组满足 `use_kd` 时，8 条回答的全部有效 completion positions 都参与 KD。

将互斥的 `if KD / elif RL` 改为可同时累加的两个条件。对 KD+RL 题组，在同一批学生回答上计算原 KL 和原 RL 项：

\[
L=\frac{\sum_{j,i,t} M_j^{KD}\ell^{KD}_{j,i,t}
+\sum_{j,i,t}M_j^{RL}\ell^{RL}_{j,i,t}}{Z}.
\]

`Z` 始终是本轮全部 32 条回答的有效 completion token 数，包含跳过组，KD+RL 位置只在分母计一次。保留原来两个分支的系数 1。不要分别归一化分支，不要按新增 KD 覆盖率重新缩放损失。

允许复用学生 forward 或分开 backward，但必须在参数未更新的条件下累计全部梯度，最后只做一次全局梯度裁剪和一次 optimizer step。
